# kyg-home 문서

개인 홈페이지 프로젝트 문서입니다. 목적에 따라 아래 문서를 참고하세요.

- [local-development.md](./local-development.md) — 로컬에서 프론트/API 서버 띄우는 방법, 환경변수, 알아두면 좋은 이슈들

## 한눈에 보기

- **프론트엔드**: React + Vite (`src/`)
- **백엔드**: Vercel Serverless Functions (`api/`)
- **DB**: Neon Postgres (서버리스 HTTP 드라이버)
- **파일 저장소**: Vercel Blob (private 스토어)
- **배포**: Vercel, GitHub(`kyg300/kyg-home`) 연동 시 `main` 브랜치 push마다 자동 배포

## 현재 기능

- 로그인 / 로그아웃 (JWT 쿠키 기반). 회원가입 기능은 없음 — 계정은 DB에 직접 추가
- 게시판 글쓰기 / 목록 / 상세 / 수정 / 삭제 (본인 글만 수정·삭제 가능)
- **로그인하지 않으면 게시글을 볼 수 없음** (목록·상세 API 모두 인증 필요)
- 홈 화면: 검색바 + 바로가기 + 로그인 시 최근 게시글 카드
- 게시판 검색 (`/board?q=검색어`, 제목·내용 클라이언트 필터)
- 게시글 첨부파일: 이미지/문서 최대 5개, 개당 10MB, 업로드·미리보기·다운로드·삭제
- 지도(`/map`): 카카오맵 SDK로 지도 표시 (로그인 필요)
- 기록(`/notes`): 할 일(체크/삭제/완료 항목 일괄 삭제), D-day(D-n/D+n 자동 계산), 메모(작성/수정/삭제). 사용자별로 DB에 저장되고 홈 화면 "오늘" 패널에 남은 할 일과 다가오는 D-day 표시 (로그인 필요)
- 날씨(`/weather`): 전국 16개 도시 중 선택, 현재 날씨·체감·습도·바람·미세먼지·일출/일몰 + 24시간 예보 + 7일 예보. 고른 도시는 브라우저에 저장되고 홈 화면 위젯도 같은 도시를 보여줌 (로그인 필요)
- 다크 모드: 상단 메뉴의 버튼으로 시스템 설정 → 라이트 → 다크 순서로 전환, 선택은 브라우저에 저장
- 시세(`/stock`): 종목을 검색해서 직접 추가·삭제하는 사용자별 관심종목(최대 30개) + USD/EUR/JPY/CNY 환율 + 비트코인/이더리움/리플 코인 시세, 10초 자동 갱신 + 수동 새로고침 + 카운트다운 표시 (로그인 필요)
- 번역(`/translate`): MyMemory API로 텍스트 번역, 언어 선택/스왑 지원 (로그인 필요)
- 스포츠(`/news`): 연합뉴스·SBS·동아일보 스포츠 RSS 3개를 합쳐 최신순으로 표시, 제목 클릭 시 새 탭에서 원문으로 이동 (로그인 필요)
- 급상승검색어(`/trends`): 구글 트렌드의 대한민국 실시간 인기 검색어 10개를 순위·관련 뉴스와 함께 표시 (로그인 필요)
- 운세(`/fortune`): 12지 띠를 고르면 날짜+띠 기반으로 매일 바뀌는 총운/금전운/애정운/건강운과 운세 점수 표시, 외부 API 없이 자체 생성 (로그인 필요)
- 홈 화면 날씨 위젯: Open-Meteo API로 선택한 도시(기본 서울)의 현재 기온/날씨/오늘 최고·최저기온 표시, 누르면 날씨 페이지로 이동 (로그인 필요)
